# BATTLE AGAINST A TRUE HERO · 像素 MV

基于 UNDERTALE 曲目 *Battle Against a True Hero*（150 BPM）编排的像素演出：不死的安黛因之战。无构建步骤，打开 `index.html` 即可播放，全片 3 分 13.8 秒。

**成片下载：[video/undyne_mv_v8_720p60.mp4](video/undyne_mv_v8_720p60.mp4)**（第八版 · 加入前置过场，1280×720 **60fps**，3:13.8，已混入音乐与音效；在 GitHub 页面点 “Download raw file” 下载）

做法沿用 [guiguisocute/mtt-mv-pub](https://github.com/guiguisocute/mtt-mv-pub)（镁塔顿演出战）：Canvas 像素世界 + WebGL 后期，所有画面都是时间的纯函数，按音乐分析出的拍点编舞；导出时用无头 Chromium 逐帧渲染再用 ffmpeg 编码，不用任何视频模型。

叙事：一场**谁也打不倒谁**的战斗。玩家的绿色灵魂用盾挡下她的每一支长矛，红色灵魂躲开每一次突刺（HP 全程 64 / 64）；她每吃一刀都笑着站起来，直到最后一个和弦。开场和结尾都没有音乐：开场她替孩子挡下一刀、开始融化、拒绝倒下；结尾她化作尘埃。

**游戏致敬**：六个经典游戏的设计被翻译成这场战斗自己的语言（长矛、绿盾、红魂、瀑布），同样的像素画风。前半段先"铺垫"——机制第一次出现、规则讲清楚、还没爆发；后半段再"兑现"。

**画面与 3D**：

- **电影画幅**：上下黑边。Boss 名字、血条、命在上黑边里；玩家的 HP 与四个按钮固定在下黑边里（屏幕空间，镜头怎么推都不会被切）。只狼的架势条贴在战斗框正上方。镜头自动避让：她的头和战斗框始终留在两条黑边之间；台词气泡被限制在画面内，大字喊话在她身体两侧。
- **2D → 3D → 2D**：
  - 28、80 **立方体转场**：上一阶段的最后一帧变成立方体的一面转走，新的画面作为下一面转进来（后期着色器里光线求交）。
  - 44–51 **战场倒下**：整个战场向后倒成透视地面，镜头压低到灵魂背后；地面网格随拍子流动，长矛贴地飞来，她的影子铺在地上。安黛因在"站立层"上——以她的脚为轴、始终正对镜头的立板——所以她依然站着；51 地面抬回平面。
  - 72 **体素环绕**：她复活时，像素图逐像素长出厚度变成体素模型，在血条回满的同时原地转一整圈，下一个强拍压回 2D 像素图。
  - 88 **玻璃碎屏**：上一帧画面被切成三角碎片，带透视翻滚着朝镜头飞散，露出后面的全屏战场。
  - 94–95 **第一人称**：镜头钻进灵魂，变成它的视角——她的脸悬在消失点、独眼燃烧，长矛沿四条通道从黑暗里直刺镜头，被视野边缘的盾牌弧挡下；95 末尾视野收回灵魂，接回 2D 的最后一刀。

**打击与受击反馈（第六版）**：

- **三层弹幕密度**：重音（拍手、旋律）负责重击；乐句推进时，踩镲的八分音符逐渐填满空拍；高潮处加入十六分音符连射，盾按顺时针一路转过去。峰值密度约为原版的两倍，全片 336 支绿矛。
- **八连冲**：乐句尾不再是四连刺，而是从八分加速到十六分的八连刺，每一支都比上一支快；最后一支从反方向重击。
- **弹反**：部分重击被盾弹回，回旋的长矛划着弧线飞回去扎在她身上——护甲火花、她白闪后仰、换上受伤的脸，只狼的架势条猛跳一截。
- **她亲自出手**：红魂阶段（32、43）她跳出画面，持矛从天而降贯穿战斗框的一列（先亮警示列），砸出冲击波；追逐段里她越过灵魂插矛拦路。
- **受击手感**：每次格挡灵魂被推开 2–4 px 再弹回、盾弧被砸凹；最重的格挡带极短的顿帧。

**二阶段「真正的英雄 安黛因」（第七版加强）**：72 起一切翻倍，要让人觉得遇上了打不赢的对手。

- 绿盾风暴：每小节空拍全部填满，第 2、4 拍都有十六分连射；每个重音是三支矛汇成一束的齐射；她每半小节瞬移一次；每两小节画面整个裂开（裂纹 + 碎片 + 一下红闪）。
- 符卡：千本之矛加外层矛帘、下方反向矛帘；瀑布之雨·极在反拍先从地面升起下一拍的矛柱；绽放每停一次四朵矛花；不死之身每拍一朵矛花，合围从 24 支变 48 支；85 她再一次从天而降。
- 矛墙在反拍再从另一侧追加一道；瀑布追逐里地刺、贴地矛都成对出现，空拍再加高空飞矛；95 的过门变成每个十六分音符一支、共 16 支。
- 全程更重的震屏、更深的暗角、她身后更大的暗影、满屏升腾的火星；最后一刀把整个画面劈碎。

**Boss 的威压**：她身后始终站着一个巨大的暗影，独眼燃着红光；她身上烧着蓝色的气焰；镜头一直在震。她不站桩：猛扑、跳上空中再砸地、边冲刺边投矛；每一次格挡都把镜头往后踢；乐句开头是动画式的 Boss 特写插画（cut-in）和大字台词；背景里巨型长矛不停地横贯画面。

## 本地播放

```sh
node tools/serve.cjs                 # http://127.0.0.1:4173
```

也可以直接用浏览器打开 `index.html`（`file://` 即可）。

- `空格` / `Z`：播放 / 暂停
- `←` `→`：快退 / 快进 2 秒（按住 Shift 为 1 小节）
- `D`：显示时间 / 小节 / 段落
- 点击底部进度条跳转
- URL 参数：`?t=40` 从 40 秒开始；`?lat=0.03` 调整画面与声音的延迟校准

## 导出成片

需要 Node、ffmpeg，以及 Playwright Chromium：

```sh
npm install playwright
npx playwright install chromium
node tools/render.cjs --gpu --vcodec=h264_nvenc --workers=2   # 有 N 卡
node tools/render.cjs --workers=4                             # 纯 CPU（SwiftShader，较慢）
# → dist/mv_1080p60.mp4（1920×1080 60fps，已混入音效）
```

其余参数（`--fps --w --h`、`--t0 / --t1`、`--frames=dist/frames`、`--audio-only`、`--limit`）见 `tools/render.cjs` 文件头。

## 规则

- **绿色灵魂**：长矛从上下左右四个方向飞来，盾必须在长矛落地的那一刻正对它（`tools/check.cjs` 逐支校验）。黄色长矛先从一侧逼近，再绕到背后从反方向刺来。
- **红色灵魂**：先定灵魂的路线，再沿路线布置长矛 / 光束；240 Hz 逐帧检测，没有任何一次接触。
- 长矛的落点跟着鼓点：反拍的拍手（第 2、6、10、14 个 16 分位）+ 旋律重音；方向跟着旋律：音往上走从上方来，往下走从下方来，平行则左右交替。
- 一个画面一个机位，镜头只在乐句边界上大幅移动；场景切换都由音乐的过门（fill）带过去。

## 音乐分析

`tools/analyze_music.py`（librosa）把分析结果写入 `src/analysis.js`。

| 项目 | 结果 |
| --- | --- |
| 速度 | **150 BPM 全曲恒定**，一拍 0.4 s，一小节 1.6 s |
| 首拍 | 0.002 s |
| 长度 | 156.8 s = 98 小节（最后一击在第 96 小节，之后余音） |
| 段落 | 0–3 独奏 riff · 4–10 贝斯 · 11 过门 · 12–27 全乐队 · 28–43 / 44–59 主题 ×2 · 60–71 间奏 · 72–95 终章（8+8+8）· 96 收尾 |

`src/analysis.js` 提供逐 16 分的 `kick / snare / hat / tone` 强度、旋律音高 `lead`、逐拍低音 `bass`，供长矛落点、方向和镜头冲击取用。
